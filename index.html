About
What I do

I'm a software engineer with a frontend foundation — 4+ years of professional React, Next.js, and TypeScript across e-commerce, edtech, maritime, and healthcare products. Right now I build e-commerce platforms for Magrabi and Doctor M at Forchunex IT Consultancy.


Outside work, I build local-first, AI-powered developer tools. My main project is PIE — a Rust + Tauri desktop app that transcribes speech entirely on-device (whisper.cpp + Silero VAD), extracts intent, and delivers a structured prompt to your cursor in any application. Building it has meant real systems work: audio pipelines, a layered pronunciation corrector, integration tests against a mock LLM, signed releases, and a Homebrew tap. AI coding tools like Claude Code are part of my daily workflow; I'm currently going deeper into retrieval and agent architectures by building, not just reading.
